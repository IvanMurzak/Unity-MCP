# Documentation

Languages: English (source), `zh-CN`, `ja`, `es`, `fa`, `hi`, `ar`. Never add Russian. `fa` and `ar` are RTL.

```
README.md                                                        ← Root project documentation
Unity-MCP-Plugin/Packages/com.ivanmurzak.unity.mcp/README.md     ← Byte-identical copy of README.md *
Installer/Assets/com.IvanMurzak/AI Game Dev Installer/README.md  ← Byte-identical copy of README.md *
docs/README.<lang>.md                                            ← Translations of README.md *
docs/<page>.md + docs/<page>.<lang>.md                           ← installation, mcp-server, custom-tools, benchmark,
                                                                   default-mcp-tools, ci-disable, DOCKER_DEPLOYMENT *
docs/dev/Development.md + Development.<lang>.md                  ← Developer guide *
cli/README.md + cli/docs/README.<lang>.md                        ← CLI README (shipped in the npm package) *
cli/docs/commands.md + cli/docs/commands.<lang>.md               ← CLI command reference (shipped in the npm package) *
docs/img/{readme,benchmark}/*.svg, docs/img/button/*.svg            ← Generated by docs/img/readme/build-svgs.py
```

Files marked with `*`: when the English source changes, update every translation of it in the same change.
Refresh the two README copies with `Unity-MCP-Plugin/Commands/copy_readme.bat` (or a plain copy).

The root README and the CLI READMEs are shown on OpenUPM and npm, which do not resolve relative paths:
use absolute `https://raw.githubusercontent.com/IvanMurzak/Unity-MCP/main/...` image URLs and
`https://github.com/IvanMurzak/Unity-MCP/blob/main/...` doc links there.

Regenerate the generated SVGs with `python docs/img/readme/build-svgs.py`; do not hand-edit them.
